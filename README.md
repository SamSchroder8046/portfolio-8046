# Portfolio-8046

Portfolio-8046 is a personal portfolio site where users can view personal projects made by Samuel T. Schroder.

## Installation

While under development, you can still view the site via. the steps below.

1. Install [UniServerZ](https://sourceforge.net/projects/miniserver/).
2. Clone repository into 'UniServerZ/www/' directory.

```bash
cd [desired-directory]
git clone https://github.com/SamSchroder8046/portfolio-8046.git
```

3. Visit 'localhost/[path-to-project-directory]/index.php' in your browser.

## Usage

Alternatively, visit the deployed site [here](https://portfolio-8046.free.nf/public/index.php) (WIP)
